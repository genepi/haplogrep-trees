# HaploGrep Trees

The central repository for phylogenetic trees used by [HaploGrep 3](https://github.com/genepi/haplogrep3).

Browse all available trees: **[genepi.github.io/haplogrep-trees](https://genepi.github.io/haplogrep-trees)**

## Add a tree

Update the `trees.json` file and open a pull request to publish your tree.

## Citation

Schönherr S, Weissensteiner H, Kronenberg F, Forer L. *HaploGrep 3 - an interactive haplogroup classification and analysis platform.* Nucleic Acids Research, 2023. https://doi.org/10.1093/nar/gkad284

## Available Trees

HaploGrep 3 supports the following phylogenetic trees for haplogroup classification. The full catalog is maintained at [genepi.github.io/haplogrep-trees](https://genepi.github.io/haplogrep-trees) and defined in [`trees.json`](https://github.com/genepi/haplogrep-trees/blob/main/trees.json).

| ID | Description | Latest | Repository | Reference |
| --- | --- | --- | --- | --- |
| `phylotree-fu-rcrs` | PhyloTree 17 – Forensic Update (rCRS Human mtDNA) | 1.3 | [genepi/phylotree-fu-rcrs](https://github.com/genepi/phylotree-fu-rcrs) | [1] |
| `mitotree-rcrs` | FamilyTreeDNA Mitotree (rCRS Human mtDNA) | 2026.05.06 | [genebygene/mitotree](https://github.com/genebygene/mitotree) | [2] |
| `mitotree-rsrs` | FamilyTreeDNA Mitotree (RSRS Human mtDNA) | 2026.05.06 | [genebygene/mitotree](https://github.com/genebygene/mitotree) | [2] |
| `phylotree-rcrs` | PhyloTree (rCRS Human mtDNA) | 17.3 | [genepi/phylotree-rcrs-17](https://github.com/genepi/phylotree-rcrs-17) | [3] |
| `phylotree-rsrs` | PhyloTree (RSRS Human mtDNA) | 17.2 | [genepi/phylotree-rsrs-17](https://github.com/genepi/phylotree-rsrs-17) | [3], [4] |

> **Note:** The FamilyTreeDNA Mitotree is provided for **non-commercial use only**.
